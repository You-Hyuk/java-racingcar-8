# java-racingcar-precourse
## 구현 기능 목록
### 입출력
- 사용자에게 입력 문구 출력 및 자동차 이름, 시도 횟수를 입력 받는다.
- 시도 횟수 만큼 자동차 경주의 결과를 출력한다.
- 자동차 경주의 최종 우승자를 출력한다. 우승은 가장 많이 전진한 자동차이다. 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
### 엔티티
- 자동차 객체를 구현한다.
- 엔티티 비즈니스 로직 메소드를 구현한다.
### 자동차 이름 파싱
- 자동차 이름을 쉼표(,)를 기준으로 파싱한다.
- 이름이 5자 이하가 아닌 경우 `IllegalArgumentException`을 발생시킨다.
### 자동차 경주
- 자동차 전진을 구현한다. 전진의 기준은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상인 경우이다.
- 사용자가 입력한 이동 횟수만큼 자동차 경주를 진행한다.
- 자동차 경주 우승자를 조회한다.
### 테스트
- 자동차 이름, 시도 횟수의 입력값이 실제 입력값과 동일한지 확인한다.
- 입력받은 자동차 경주 횟수와 실제 횟수가 동일한지 확인한다.
- 가장 많이 전진한 자동차가 우승하는지 확인한다.
- 자동차 이름을 쉼표를 기준으로 적절히 파싱하는지 확인한다.
- 이름이 5자 이하가 아닌 경우 `IllegalArgumentException`가 발생하는지 확인한다.
- 자동차가 무작위 값이 4 이상인 경우에만 전진하는지 확인한다.
- 여러 명의 우승자가 존재하는 경우 쉼표(,)를 이용해 구분되어 출력되는지 확인한다.
